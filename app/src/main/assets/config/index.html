Getting started

There are two kinds of channel. Each gets a number that is typed on the remote.

  1. IPTV (from an IPTV subscription). In IPTV providers below, add the server address, username and password your provider sent you, or the playlist link they gave you. Press Save providers, then Import channels and tick the categories you want. For a single stream link, use + Add channel and leave the type on Stream.
  2. YouTube. Use + Add channel, set the type to YouTube and paste a live link or channel ID. To avoid ads with your YouTube Premium account, choose In the YouTube app at the bottom of this page.

Then press a number on the remote. Channel up/down and numbers also work while YouTube is playing.

TV language

Language of the words on the TV screen. Channel names stay as the provider sends them.

IPTV providers

Your IPTV subscription. Most providers give a server address, a username and a password (Xtream Codes). If you only have a playlist link, choose M3U link. Passwords stay on the TV and are never shown here again.

Import a playlist (M3U)

Paste the M3U URL from your IPTV provider, or paste the playlist text. Imported channels are added after the highest existing number.

YouTube channels

Set type to YouTube and paste a live video link, a youtube.com/live/… link, or the channel ID (starts with UC) to always show that channel's current live stream.

Home guard

Keeps the TV on Simple TV. The Home button comes back here, and the assistant and app shortcut buttons on the remote do nothing. Pause it when you need Google TV's own settings, for example to change Wi-Fi.

YouTube "Who's watching?" screen

YouTube sometimes asks who is watching. Simple TV can answer for you by choosing the first account, but it has to learn what that screen looks like once. The next time it appears on the TV, press Remember this screen while it is still showing.

Remote buttons

Press buttons on the TV remote, then press Refresh. Each press shows its code. Use Block on any button that opens something it should not, such as a Netflix or YouTube shortcut. Buttons Simple TV needs cannot be blocked.
